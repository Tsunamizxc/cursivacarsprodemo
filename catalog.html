Инструкция по API парсера

																								

										
1. Как работает парсер

										
Тема сама загружает объявления с Encar, AutoScout24, Dongchedi и др., сохраняет их в data/parser-cache/ и показывает в каталоге. Сторонний API не нужен. Автосинхронизация — 2 раза в сутки (WP-Cron).

									

																	

										
2. Синхронизация вручную

										
Нажмите «Синхронизировать сейчас» или отправьте POST-запрос (нужна авторизация администратора WordPress): #autoimport/v2/sync

									

																	

										
3. Получить объявления (Postman)

										
GET #autoimport/v2/platforms — список платформ. GET #autoimport/v2/encar/offers?page=1 — объявления из кэша (page=1,2,…). GET #autoimport/v2/encar/offers?page=2&live=1 — страница 2 напрямую с Encar (live=1). GET #autoimport/v2/encar/offer?inner_id=ID — одно объявление по inner_id. В ответе meta.pages, meta.next_page, meta.prev_page.

									

																	

										
4. Скрытие и редактирование

										
Нажмите «×» на карточке, чтобы скрыть авто. Кнопка «✎» — изменить название, цену и описание для посетителей (данные API не перезаписываются).

									

																	

										
5. Настройки

										
В админке WordPress: Настройки темы → Каталог → провайдер «Parser», выбор площадок, курсы валют, число страниц sync.
